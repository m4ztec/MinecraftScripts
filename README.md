# Minecraft Scripts

This workspace separates Pathmind preset tooling from Minescript scripts:

- [`pathmind/`](./pathmind/): the preset builder library, JSON presets and schema, tests,
  and preset-generation script. See [Pathmind documentation](./pathmind/README.md).
- [`minescript_scripts/`](./minescript_scripts/): standalone Minescript scripts.

There are no Minescript scripts in the workspace yet.
